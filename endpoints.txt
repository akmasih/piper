What the web host serves from the packs this repository builds (static files, nginx, read-only).

Base URL: https://oropen.com/packs/   (web repo: deployment/packs/nginx.conf)

================================================================================
1. MANIFEST
================================================================================
   GET /packs/manifest.json
   Cache-Control: no-cache (always revalidated; ETag)

   {
     "schema": 1,
     "generated_at": "2026-09-28T12:00:00+00:00",
     "engine":   { "name": "sherpa-onnx", "version": "1.13.8" },
     "runtimes": { "web": "runtime-web" },
     "components": {
       "<component id>": {
         "kind": "runtime" | "tts_data" | "tts_voice" | "stt_model",
         "version": "<16 hex, derived from the files>",
         "size": <bytes, all files>,
         "license": "...",
         "attribution": "...",
         "requires": ["<component id>", ...],
         "files": [ { "path": "...", "size": <bytes>, "sha256": "<hex>" } ],
         "tts": null | {
           "model_type": "vits", "model": "<file>", "tokens": "tokens.txt",
           "data_dir": "espeak-ng-data",          (inside the required espeak-ng-data component)
           "sample_rate": 22050, "language": "en", "locale": "US",
           "gender": "female" | "male", "display_name": "Kristin"
         },
         "stt": null | {
           "model_type": "nemo_transducer" | "whisper",
           "files": { "encoder": "...", "decoder": "...", "joiner": "...", "tokens": "..." },
           "languages": ["en", "de"],
           "max_input_sec": 60,
           "sample_rate": 16000
         },
         "source": { ... provenance ... }
       }
     },
     "packs": [
       { "id": "tts-en", "feature": "tts", "language": "en",
         "components": ["tts-en_US-kristin-medium", "tts-en_US-norman-medium"],
         "default_voice": "tts-en_US-kristin-medium" },
       { "id": "video-stt-fa", "feature": "video_stt", "language": "fa",
         "components": ["stt-whisper-turbo-timestamps-int8"], "default_voice": null }
     ]
   }

   A client installs a pack by installing its components, each component's
   "requires" (transitively), and on the web also runtimes.web.

================================================================================
2. COMPONENT FILES
================================================================================
   GET /packs/components/<component id>/<version>/<file path>
   Cache-Control: public, max-age=31536000, immutable
   Accept-Ranges: bytes (an interrupted download resumes with Range)

   Example:
   curl -O https://oropen.com/packs/components/tts-en_US-kristin-medium/<version>/en_US-kristin-medium.onnx

   Every file must match the size and sha256 listed in the manifest; a client
   discards a file that does not and reports the failure.

================================================================================
3. HEALTH
================================================================================
   GET /packs/health   ->  200 "ok"   (nginx itself; does not read the packs)
